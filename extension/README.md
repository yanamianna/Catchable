# 在日常 Chrome 中安装 Catchable

本扩展连接现有本机订座系统，并在当前 Chrome 的登录资料内新建 Catchtable 标签页。保持 Chrome 打开即可，无需使用专用小窗口或关窗交接登录。

1. 启动项目里的“启动订座系统.cmd”，打开 http://127.0.0.1:4174/。
2. 在日常 Chrome 打开 `chrome://extensions/`，打开“开发者模式”，点击“加载已解压的扩展程序”，选择本项目的 `extension` 文件夹。控制台点击“显示配对码”后，也会显示当前电脑上的完整安装目录。
3. 在本机系统的登录面板点击“显示配对码”及“复制配对码”。在 Chrome 工具栏打开“Catchable 本地订座助手”，粘贴配对码并点击连接。
4. 在这个日常 Chrome 中登录 Catchtable。回到本机系统点击“核验扩展登录”；账号页及新页面核验通过后，再恢复需要执行的任务。

Chrome 安装时需要你授予 `debugger`、`tabs`、`storage` 权限。`debugger` 是 Chrome 的网页调试接口，系统用它执行页面点击、填写已授权的预约资料及读取官网核验结果。代码只控制助手新建的 Catchtable 标签页，不关闭个人标签页或整个 Chrome，也不导出 Cookie、认证头或浏览器登录资料。Chrome 显示调试横幅属于正常情况；撤销调试会停止操作。

配对码只连接本机 `127.0.0.1:4174`，不要分享。扩展不使用远程代码或外部服务器，不将配对码放入 Chrome 同步。后台重启会自动重连，但不会重放先前的预约提交。

当前代码已经通过离线通信、真实隔离 Chrome 页面、控制台交互及重复提交保护测试。你的实际 Chrome 扩展安装与官网登录状态须在安装配对后核验，不能以这些离线测试代替。
