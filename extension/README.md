# Catchable Chrome 扩展

每个 Catchtable 账号使用独立 Chrome 用户资料，并在该资料中加载一次本扩展。

1. 启动订座系统，在 `chrome://extensions/` 开启开发者模式，加载本目录。已有扩展点击一次「重新加载」。
2. 在对应 Chrome 中打开 http://127.0.0.1:4174/，选择账号并点击「连接此浏览器并核验」。系统会连接扩展并核验 Catchtable 登录；未登录时在打开的官网页面完成登录。
3. 以后保持 Chrome 打开，扩展会自动重连，无需重复配对。更换账号绑定时会单独确认。

控制台与扩展不在同一个 Chrome 中时，可在扩展「使用配对码连接」输入控制台显示的 8 位数字码。旧版配对码仍然有效。配对码明文显示，只连接本机，不进入 Chrome 同步。

扩展沿用 `debugger`、`tabs`、`storage` 权限，只控制助手新建的 Catchtable 标签页。控制台连接脚本仅运行于本机 4174 端口（及开发用 4173 端口），不会导出 Cookie 或登录资料。后台重启自动重连，不重放预约提交。
